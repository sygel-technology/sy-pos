=========================
POS Receipt Employee Name
=========================

This module allows to select the employees' names that have to be shown in POS receipts.


Installation
============

To install this module, you need to:

#. Only install


Configuration
=============

To configure this module, you need to:

#. Go to the form view of an employee and configure the name that has to be shown in POS receipts in the field "POS receipt name".
