This module allows to customize the employee names that will be shown in
the POS receipts.

Configuration
=============

To configure this module, you need to:

1. Go to the form view of an employee and configure the name that has to
   be shown in POS receipts in the field "POS Receipt Name".
2. Go to the settings of your point of sale. Activate the "Log in with
   Employees" option

Usage
=====

To use this module, you need to:

1. Go to Point of Sale. Open a session with your configured register.
2. Select your configured employee or enter your pin
3. Sell some items and click on Payment -> Validate
4. The pos order report will be shown. There will appear "Served by"
   followed by the name you configured in the "POS Receipt Name" field.

Known issues / Roadmap
======================

-  If you do not activate the "Log in with Employees" option, this
   module is unable to read the employee from the POS and it does not
   work.
