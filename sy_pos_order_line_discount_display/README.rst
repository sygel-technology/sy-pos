This module improves the display of prices and discounts in POS (Point
of Sale) order lines. It allows splitting and showing separately:

- Pricelist Discount: automatically applied by the active pricelist
- Manual Discount: applied by the POS user

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Open the Point of Sale.
2. Add a product with a Pricelist Discount and apply a Manual Discount.
3. In the order line, the discount breakdown will appear under the
   product name (e.g., “10% discount + 5% discount”).
